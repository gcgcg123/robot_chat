# 三語聲紋登記與使用者管理

更新日期：2026-09-14。新版本啟動時自動遷移至資料庫 schema 3。

## 使用流程

1. 登入 Dashboard，在使用者列表按「註冊新使用者」，進入 PC 模擬器。
2. 填寫姓名、性別、年齡（可留空）及偏好對話語言：粵語、普通話或 English。
3. 選擇朗讀範本語言並按「開始登記」。每種語言有三段不同短句。
4. 按「開始錄音」，自然朗讀約 5–10 秒，按「停止錄音」（20 秒會自動停止）。
5. 試聽錄音，可以不限次重錄；滿意後按「確認並繼續」。後端保存成功才顯示 toast 並前進。
6. 第三步按「確認並完成登記」。完成後才能顯示成功狀態。上傳失敗保留預覽；完成請求可安全重試。
7. 語音對話會先以 ECAPA-TDNN 聲紋嵌入比對；只有 accepted 才會轉寫及回答。瀏覽器播放相應語言的音色。

錄音過短、音量過小或爆音會被拒絕。檢查基於 PCM 音量及長度，尚非精準語音活動或朗讀內容檢查，背景噪音仍可能通過。更換人或語言前先取消登記。登記 10 分鐘逾時；重新整理或後端重啟後需重新開始。取消或失敗不覆寫舊模板，三段完成後才替換。

## 語言的作用

- preferred_language：偏好對話語言，影響 LLM 系統指示、fallback 回覆及瀏覽器 TTS 選音。
- enrollment_language：最近一次成功登記的範本語言，和對話偏好獨立。
- 新使用者預設粵語；舊使用者遷移保留普通話預設，登記語言顯示未記錄。可在個人資料頁編輯。
- ASR 預設自動判斷，適合混合語言；取消自動判斷後，依偏好傳入 yue、zh 或 en。現有 faster-whisper 套件確認包含 yue。
- PC 播放使用 Web Speech API 的可用系統音色，粵語只選粵語／香港中文音色。缺少音色會提示，只顯示字幕，不假裝播出粵語。
- 瀏覽器音色可能由系統供應商提供；ESP 的服務端語音合成仍待第二階段。當輪要求換語言可影響 LLM 文字，但語音音色仍以個人偏好選擇。

## 管理功能

使用者列表顯示對話語言；點選使用者可編輯姓名、性別、年齡、偏好語言，或重新登記、停用／啟用、刪除。刪除前需輸入使用者 ID。

刪除會清除此使用者的聲紋、對話、分析、風險、個人記憶、同意記錄及 audio_turns，取消未完成登記，解除裝置關聯並保留裝置。保留最小刪除 ID 標記及管理操作稽核，阻止舊對話請求重新建立已刪使用者。已有備份不自動清除。既有媒體快取按原本保存策略處理，本次登記錄音不另存檔。

## 聲紋驗證與限制

正式啟動預設使用 SpeechBrain ECAPA-TDNN（`ecapa-voxceleb-v1`），登記及識別只會比較相同模型版本的模板。未知聲音或分數不夠會回傳 unknown，兩個使用者分數太接近會回傳 ambiguous；WebSocket 也會在後端驗證 active template，不能只靠前端傳入 user_id。

模型首次使用時會下載到 `models/voiceprint/ecapa-voxceleb`。可用 `VOICEPRINT_THRESHOLD` 和 `VOICEPRINT_MIN_MARGIN` 調整門檻，但正式部署前必須用實際麥克風、噪音、距離和不同語言的真人樣本校準 FAR/FRR。測試模式仍使用 pc-baseline 替身，不代表真實聲紋準確率。切換模型版本後所有使用者都需要重新登記。

## 驗證及備份

自動測試涵蓋三段保存／重傳、無效格式、靜音、短錄音、取消、逾時、偏好語言、刪除保留裝置、防止重建已刪使用者及停用限制。UI 真人錄音、toast 視覺和音色聽感需使用者實測。

另以 `node tests/simulator_controller.cjs` 執行真實 simulator.js 的事件處理器，使用模擬 DOM、麥克風與 API 驗證預覽、重錄、上傳失敗重試及三步確認。這項測試不等同瀏覽器視覺驗收。
