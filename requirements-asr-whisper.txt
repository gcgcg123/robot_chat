# service starts, transcribes and remembers without it; only ASR_PROVIDER=whisper needs
# it, and then the failure message names this file.
#
# scripts/bootstrap-project.ps1 installs it automatically for -AsrModel whisper (or
# both), and it can also be requested directly with -WithWhisper.
